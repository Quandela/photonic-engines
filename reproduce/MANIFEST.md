# Reproduction manifest

One row per published result that the scripts in this directory reproduce. Every number was measured on **one NVIDIA
H100 PCIe, in fp64**, with the environment recorded in `environment-gpu.txt` at the repository root. Each
script runs, in full mode, the exact command lines of the original run; the run's log, command lines and result files
are kept under `runs/<stamp>/`.

How to run, from the repository root:

```bash
bash reproduce/<script>.sh                 # full size: the published protocol (hours for most scripts)
bash reproduce/<script>.sh --quick         # the same benches at reduced size: minutes, a smoke test only
bash reproduce/<script>.sh --out DIR       # output directory (default out/<script>)
bash reproduce/<script>.sh -h              # what the script reproduces, original runs, wall time
```

`--quick` checks that every bench and option of a script runs on your machine; its numbers are not the published
ones. Thresholds n\* are the sizes at which one GPU draws one sample per second (t_S at S = 10⁴ samples), m = 2n
unless stated. Wall times are those of the original runs. Some scripts also need third-party code (GBSKernels, The
Walrus, Piquasso, CUDA-Q); their headers say how it is installed.
